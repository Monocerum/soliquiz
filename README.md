# Soliquiz

A quiz game website built with HTML, CSS, and JavaScript, made for PUP computer science students preparing for midterms.

**Live demo:** https://monocerum.github.io/soliquiz/

## Features

- Covers Web Development, Introduction to AI, Information Assurance and Security, Software Engineering, and Trivia
- Each topic will have 10 questions, with four choices each.
- Each topic has a two-minute timer. Students must respond within the time allotted, or their exam will be automatically submitted.
- Responsive design for desktop and mobile

## Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript**
- **GitHub Pages**

## Notes

- This quiz game was created for a midterm project, and not intended as an actual, sufficient reviewer for midterm examinations.
